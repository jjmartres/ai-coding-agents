# Custom Themes

In OpenCode V2, the **Catppuccin** theme family (`catppuccin`, `catppuccin-frappe`, `catppuccin-latte`, `catppuccin-macchiato`, and `catppuccin-mocha`) is natively built in.

To add new custom themes, drop `.json` theme files into this directory conforming to the OpenCode V2 theme specification (`https://opencode.ai/theme.json`).
